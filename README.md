ATM Interface (Java)

About the Project

This project is a simple ATM Interface application developed using Java. It simulates basic ATM operations and helps users understand how banking transactions work through a program.

Features

- User login authentication
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history

Note: Keep only the features that are actually available in your Java code.

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Methods
- Scanner class

How to Run

1. Download or clone this repository.
2. Open the project in a Java IDE or terminal.
3. Compile the Java source file.
4. Run the program.
5. Follow the instructions displayed on the screen.

Learning Outcomes

- Understanding Java programming.
- Learning classes and objects.
- Practising methods and conditional statements.
- Understanding basic ATM operations.
